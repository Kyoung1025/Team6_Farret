### 5.4 중요한 분석 기준

- **Grafana 15:13경~15:17경 약 4분은 자동 전환 Lambda 실행시간이 아님.** 이는 화면에서 대략 확인한 Blackbox HTTP 검사 시간대다. 독립 프로브 원본은 **15:12:17 최초 503 ~ 15:17:56 최초 200 (339초)**로 더 정확히 관측됐으며, 두 방법의 측정 주기/시각 해상도를 구분한다.
- 팀원은 경보 이후 Lambda의 **ALB 가중치 변경 약 1초**를 보고한 바 있다. 경보 대기시간과 Lambda 실행시간, Grafana HTTP 검사의 검사 주기·실패 구간은 각각 다른 개념이다.
- AWS TG의 Healthy 복귀(2→0→2)는 AWS 서버가 다시 정상 타깃으로 등록됐다는 뜻이며, **ALB 가중치 AWS 100% 원복**과 동의어가 아니다.
- Nginx RPS 상승·WG TX 상승·온프렘 TG 요청량을 **함께** 보고 온프렘 경로로 요청이 들어왔다는 판단을 보강한다.
- HTTP 검사 성공 자체는 주문/결제/DB 정합성까지 증명하지 않는다. DB 검증은 별도의 팀원 증빙이 필요하다.
